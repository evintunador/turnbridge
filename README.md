# Turnbridge

Lossless visible-conversation continuity between coding agent CLIs.

Turnbridge captures native local transcript formats, writes normalized turns to
Conversation Ledger, and presents a unified resume experience across supported CLIs.
It can rehydrate a selected conversation into another CLI without claiming to
transfer hidden reasoning or provider-private session state.

This repository is intentionally at the design stage. It has no released API yet.

See [product intent](docs/PRODUCT_INTENT.md) and the [WIP technical design](docs/WIP_TECHNICAL_DESIGN.md).
